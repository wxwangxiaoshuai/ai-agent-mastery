## 内容与 SEO：让产品持续被搜索到

上一节讲的冷启动动作有个共同问题：**停下来流量就停**。私信要一条条发，社区帖会沉，发布平台的那一波过了就没了。

内容是唯一会复利的获客渠道。一篇写在两年前的文章，今天还在每天给你带来访问者，而你没有做任何额外的事。这是一个人做产品时最值得投入的长期资产 —— 因为它不消耗你的持续时间，只消耗一次性的时间。

代价是**慢**。内容从发布到带来稳定流量，通常要三到六个月。所以它不能救你的冷启动，只能决定你一年后的处境。

### 围绕搜索意图，不是围绕关键词

传统 SEO 教你找关键词、算搜索量、堆密度。这套东西在今天的效果已经大不如前，而且对一人公司来说是错误的重点。

正确的起点是**搜索意图**：一个人在什么心情下、带着什么问题、敲下了那句话。

同一个词背后可能是完全不同的意图：

| 搜索词 | 意图 | 他想要什么 | 对你的价值 |
|--------|------|-----------|-----------|
| 会议纪要怎么写 | 学习 | 一个模板 | 低（离付费远） |
| 会议录音 转文字 免费 | 找免费方案 | 白嫖 | 低（不会付费） |
| 会议纪要 自动提取待办 工具 | 找工具 | 一个能买的东西 | **高** |
| 某某工具 太贵 替代 | 找替代品 | 换一个 | **最高** |

第三、四行是你要争的。它们搜索量小得多，但**搜的人已经准备好付钱了**。

一人公司的内容策略应该是**放弃大流量词，专攻小而精准的意图**。一篇能稳定带来 50 次月访问但转化率 10% 的文章，价值超过一篇 5000 次访问但转化率 0.1% 的文章 —— 而且前者你写得出来，后者你争不过大站。

### 三类值得写的内容

**第一类：具体问题的具体解法。**

标题形如「怎么把 X 转成 Y」「X 报错 Z 怎么解决」。搜这些的人有明确的当下问题，你的文章解决了它，顺带提一句「这件事我做了个工具自动化」，转化路径极短。

写作要点：**先给答案，再讲原理**。搜索来的人没耐心看你铺垫，第一屏就要能解决问题。

**第二类：你自己的真实过程和数据。**

「我用 X 做了 Y，这是完整过程和踩的坑」「我统计了半年的 Z，发现……」。这类内容的优势是**别人抄不了** —— 它来自你的真实经历，AI 生成不出来，竞品也复制不了。

这类内容在社交渠道的转发率也最高，属于一次投入两个渠道。

**第三类：对比和选型。**

「A 和 B 怎么选」「X 的几个替代方案」。搜这类的人处在决策末期，转化率最高。

写这类内容有个纪律：**必须诚实，包括说竞品哪里比你好**。读者能分辨出软文，一篇明显偏袒自己的对比文会同时失去信任和排名。诚实地说「如果你需要 X 功能，去用竞品；如果你在意 Y，我的更合适」，反而能建立可信度并带来更精准的转化。

### AI 生成内容：机会和陷阱

用 AI 批量生成文章，是过去两年最多人试也最多人翻车的做法。

**陷阱在于**：AI 生成的通用内容没有任何独特信息。它把互联网上已有的说法重新组合了一遍，读者读完什么也没得到，搜索引擎也越来越擅长识别这类内容。批量发一百篇这样的文章，通常的结果是没有流量，且可能拖累整站质量评价。

**机会在于**：AI 能极大加速那些**你有独特信息但懒得写**的内容。

具体的分工是：

```
你提供：真实数据、真实经历、具体的坑、你的判断和取舍
AI 负责：结构组织、语言润色、扩写例子、生成配套的代码示例
```

一个实用的工作流：

```
1. 你口述（或潦草记下）一件真实经历的全部要点，包括数字和细节，10 分钟
2. 让 AI 按你给的结构整理成文，明确要求「只用我提供的事实，不要补充你知道的通用建议」
3. 你逐段核对，删掉所有你没说过的内容（这一步一定会删掉不少）
4. 你自己重写开头和结尾（这两处最能体现是不是真人写的）
```

第 2 步那句约束很关键。不加的话，AI 会自动往里填充大量正确但无用的通用建议，把你的独特信息稀释掉。

第 3 步「删掉所有你没说过的内容」是质量的保证线。**能留下来的都是只有你能提供的**，那才是这篇文章的价值。

### 内容到产品的转化路径

写了内容没有转化，通常是因为路径断了。

**别在文章里硬插广告。** 读者在解决问题，被打断会直接关掉。

**有效的位置有三个：**

一是**问题解决之后**。读者刚获得了价值，这时候提一句「这个流程我做成了工具，如果你需要经常做，可以省掉这几步：<链接>」，接受度最高。

二是**文章正文里自然出现**。如果你的文章是「我用 X 做了 Y」，而 X 就是你的产品，那它自然会出现在过程里，不需要额外推销。

三是**一个固定的作者简介区块**。每篇文章末尾一句话说明你是谁、你做了什么，长期积累的效果好于零星的插入式推广。

**转化路径要短。** 文章 → 落地页 → 注册 → 使用，中间每多一步都会掉一半人。可以考虑的做法是让文章里的链接直接进入产品的试用状态（不需要注册就能试一次），把注册往后推。

**还要能测。** 给不同文章的链接加上标记参数，你才知道哪篇文章真的带来了用户：

```
https://yourapp.com/?from=blog-meeting-todo
```

然后在漏斗里按 `from` 分组看转化（L19-03 讲怎么搭）。没有这个标记，你只能看到总注册数，无法判断哪篇文章值得再写一篇同类的。

### 节奏：宁可少而深

一人公司写内容最现实的节奏是**每周一篇，或者每两周一篇但足够深**。

比频率更重要的是两件事：

**一、持续。** 内容的效果是累积的，写三个月停半年，等于重新开始。宁可定一个你确定能坚持的低频率（每两周一篇），也不要定一个两周后就崩掉的高频率。

**二、更新旧文。** 这一条被严重低估。一篇已经有稳定流量的旧文，把它更新到最新（补充新的做法、修正过时的信息、加一节新内容），带来的流量增长通常超过写一篇新文章 —— 因为它已经被搜索引擎认可，只是内容在老化。

每季度回头看一次：哪几篇带来了最多流量？把它们更新一遍。这是投入产出比最高的内容动作。

### 内容之外：让产品自己被搜到

除了写文章，产品本身也有几处低成本但常被忽略的地方，值得花半天一次性做好。

**每个功能页有独立的标题和描述。** 单页应用最常见的问题是全站共用一个标题，搜索引擎只能收录一个页面。给主要页面配上各自的 `<title>` 和描述，成本很低。

**结果页可分享。** 如果你的产品会生成结果（报告、图表、总结），让结果页有一个可公开访问的链接（用户可控是否公开）。这类页面天然会被用户分享出去，是一个自动增长的内容来源。注意默认必须是私密的，公开要用户显式选择。

**面向问题命名页面。** 与其把功能页叫「工作台」，不如叫「会议录音转待办清单」—— 前者只有你懂，后者正好是别人搜的那句话。

**一个真实的更新日志。** 持续更新的产品页面本身就是活跃信号，而且潜在用户在决策时会看它来判断这个产品会不会突然消失。对一人公司来说，「这个人还在维护」是个重要的信任信号。

这四件事加起来半天，之后一直生效，属于典型的一次性投入长期收益。

### 一个现实的预期

给一个粗略的时间感受，避免你在第二个月放弃：

```
第 1-2 个月：几乎没有流量。这是正常的。
第 3-4 个月：开始有零星的搜索访问，个位数/天。
第 5-8 个月：稳定增长，早期文章开始持续带量。
第 9 个月以后：如果持续写，内容成为主要获客渠道之一。
```

看清楚这条曲线，你就知道两件事：**内容必须早开始**（越晚开始，起效越晚），以及**内容不能救急**（需要立刻有用户，回到 L19-01 的一对一）。

理想的顺序是：上线第一天就开始写，同时用一对一做冷启动。半年后，一对一带来的用户和内容带来的用户会开始交叉。

### 用最小成本追踪内容效果

不需要复杂的分析工具。一个简单的数据库表 + 来源标记就能告诉你哪篇文章在产生价值：

```python
# 在你的应用里加一个极简的内容归因追踪
from dataclasses import dataclass
from datetime import datetime

@dataclass
class ContentAttribution:
    slug: str          # 文章标识，如 "meeting-todo-guide"
    source: str        # 来源标记参数 ?from= 的值
    visitor_count: int
    signup_count: int
    paying_count: int

# 在注册路由里，从 URL 参数读取来源
# GET /signup?from=blog-meeting-todo
# → 存入 user 表的 acquisition_source 字段
# → 每月跑一次归因查询：

# SELECT acquisition_source, COUNT(*) AS users, SUM(lifetime_value) AS ltv
# FROM users
# WHERE created_at >= '2026-01-01'
# GROUP BY acquisition_source
# ORDER BY ltv DESC
```

三个字段就够了：`slug`（哪篇文章）、`signup_count`（带来多少注册）、`paying_count`（最终多少付费）。每月花五分钟看一遍，你就能知道：

- 哪篇文章的转化率最高——同类型值得再写
- 哪篇文章带来了最多注册但零付费——流量质量有问题，关键词意图可能偏了
- 哪篇文章你以为是爆款但根本没带来注册——标题和内容之间的 gap 可能很大

### 动手 5 分钟

规划你的第一批内容，重点是意图而不是关键词。

1. 写下 5 个你的目标用户可能会搜的具体句子（要像真人打字的样子，不是关键词），标注每句背后的意图和离付费的距离。
2. 从中挑一个「找工具」或「找替代品」意图的，列出这篇文章的提纲，标出你有而别人没有的独特信息是什么。
3. 给你的产品链接设计一套来源标记参数格式，并确认你的漏斗能按它分组。

**验收标准**：你能指出这篇文章里至少一处「只有你能写出来」的内容（你的真实数据、你踩过的具体坑、你的取舍判断）。如果指不出来，这篇文章大概率不值得写 —— 通用内容的位置已经被占满了。

### 要点总结

- 冷启动的动作**停下来流量就停**；内容是**唯一会复利的渠道**，但需要三到六个月才起效。
- 起点是**搜索意图不是关键词**：「找工具」和「找替代品」意图的人已经准备好付钱，值得专攻。
- 一人公司应**放弃大流量词**：50 次访问 10% 转化的文章，价值超过 5000 次访问 0.1% 转化的。
- 三类值得写：**具体问题的具体解法**（先给答案再讲原理）、**你的真实过程和数据**（别人抄不了）、**对比选型**（必须诚实说竞品哪里更好）。
- AI 批量生成通用内容基本无效；正确分工是**你提供独特事实，AI 负责组织和润色**，并明确约束「不要补充通用建议」。
- 「**删掉所有你没说过的内容**」是质量保证线 —— 留下来的才是只有你能提供的价值。
- 转化位置放在**问题解决之后**；路径要短，链接要带**来源标记**，否则你不知道哪篇文章真的有用。
- **更新旧文的回报常常高于写新文**；节奏上宁可低频但持续，写三个月停半年等于重新开始。
