## 用 AI Skills 辅助产品化决策

L17-13 和 L17-14 讲的是用 OpenSpec + Superpowers 做开发。但同样的工作流用在非开发任务上，效果可能更好——因为**非开发任务你的经验更少，AI 的辅助价值更大**。

写代码你有判断力，AI 写的代码好不好你一眼能看出来。但竞品分析、定价建模、合规检查——这些你可能只做过一两次，甚至从没做过。这时候 AI 的作用不是"帮你写得更快"，是"帮你想得更全"。

### 三个场景：AI 辅助产品化决策

#### 场景一：竞品扫描与需求验证

L18-01 讲了选品，但只靠自己的判断常常有盲区。AI 可以帮你做一轮系统性的竞品扫描：

```text
用 brainstorming skill 帮我做竞品分析：

我要做的产品：[一句话描述]
目标用户：[谁来用]
核心场景：[用来做什么]

请分四步：
1. 用 web search 找出 5-10 个直接或间接竞品
2. 对每个竞品：覆盖什么场景、什么定价模型、主要差评集中在哪
3. 找出所有竞品都没覆盖的空隙（可能是机会也可能是坑）
4. 判断：这个空隙是没人想到，还是有人试过但放弃了？

输出格式：每个竞品不超过 3 行，空袭分析至少列出 3 个可能的空隙，
每个空隙标注"机会/可能是坑/需要验证"。
```

**关键**：第四步比第三步重要。一个空隙没人做，通常有两种解释：别人没发现（机会），或者别人试过发现行不通（坑）。AI 搜到的竞品差评、关停公告、社区讨论，能帮你区分这两种情况。

**实际案例**：学员做一个"AI 会议纪要自动提取待办事项"的工具。自己觉得是空白市场。AI 做竞品扫描后发现：Otter.ai、Fireflies.ai、Fathom 都做了这个功能，但用户差评集中在"提取的待办不准，还得自己改一遍"。这告诉他：功能不是空白，但**准确性**是突破口——如果他能做到"提取的待办 90% 不用改"，就有竞争力。

#### 场景二：定价敏感度分析

L18-03 讲了定价模型，但"定多少钱"这个数字本身，AI 可以帮你做更系统的分析。

```text
用 brainstorming skill 帮我做定价分析：

产品：[一句话描述]
每次调用的硬成本：$X
目标用户画像素描：[谁在用，月收入范围，付费意愿假设]

请分析：
1. 列出 3-5 个定价锚点（用户会拿来对比的产品及其价格）
2. 计算三种定价方案的单位经济模型（纯订阅 / 订阅+额度 / 纯用量）
3. 对每种方案，算：多少用户时打平？毛利 50% 需要月活多少？
4. 给一个定价建议，附上"选这个数字而不是那个数字"的理由

关于定价锚点：用户不是凭空判断你的价格贵不贵。
他会在心里说"一个月 $20？我 Netflix 也才 $15"。
虽然你的产品和 Netflix 毫无关系，但这就是锚点效应。
列出 3-5 个你的目标用户可能付费订阅的东西及价格，作为参照。
```

**AI 做定价分析的优势**：AI 没有"这个价格会不会太贵了"的心理负担。人类定价时倾向于低估——因为怕没人买。AI 可以冷冰冰地告诉你：按你的成本结构，低于 $X 就是在亏钱。

#### 场景三：合规检查清单与隐私政策草稿

L18-06 讲了合规的基础知识。AI 可以帮你生成一份**针对你的产品的**合规检查清单和隐私政策草稿。

```text
用 OpenSpec /opsx:explore 帮我做合规检查：

我的产品：
- 收集什么数据：[邮箱，用户上传的文档内容]
- 数据存在哪：[具体云服务商和地区]
- 用什么模型 API：[OpenAI API / Claude API / 其他]
- 目标用户所在地区：[中国大陆 / 美国 / 欧洲 / 全球]
- 有没有用户生成内容：[有/无]

请生成：
1. 一份针对上述信息的数据处理清单（收集→传输→存储→删除）
2. 一份隐私政策草稿，标注哪些条款是"模板可用"、哪些是"必须根据实际情况修改"、哪些是"必须律师审核"
3. 一份上线前合规检查清单，按优先级排序（上线前必须做 / 上线后尽快做 / 用户量大了才需要做）

重要：所有法律相关内容请标注"本内容由 AI 生成，不构成法律意见，
请咨询有相应执业资质的专业人士"。涉及具体法律条款的地方，
标注"此处需要律师确认"而不是给出具体建议。
```

**三个标注的意义**：

- **"模板可用"**：标准条款，比如"我们使用 SSL 加密传输数据"，基本不需要改。
- **"必须根据实际情况修改"**：里面有占位符或需要你填具体信息的地方，比如数据存储位置、联系方式。
- **"必须律师审核"**：涉及法律判断的条款，比如数据跨境传输的合法性基础、责任限制条款的措辞。**AI 可以写草稿，但不能替你判断合法性。**

### AI 辅助产品化决策的三个常见陷阱

**陷阱一：把 AI 的"建议"当成"决策"。** AI 说"建议定价 $19/月"，你直接用了。但 AI 不知道你的用户对价格的敏感度、不知道你的竞品最近降价了、不知道你打算两个月后涨价。AI 的建议是"基于你给的信息的合理推断"，不是"市场验证过的结论"。

**陷阱二：AI 的信息源可能过时。** AI 搜到的竞品定价可能是去年的，搜到的用户评价可能是被删掉的版本。关键信息（竞品价格、市场份额、法规变化）**必须自己验证**。AI 帮你缩小"需要验证什么"的范围，不是帮你免除验证。

**陷阱三：用 AI 做合规检查的"虚假安全感"。** AI 生成的合规检查清单看起来全面，但它可能漏掉你所在地区特有的法规要求，也可能把你不需要担心的条款列进去。合规检查清单是"帮你想起你可能忘了的事"，不是"保证你想全了所有事"。

### 实操：跑一遍完整流程

以"为 P18 项目做定价分析"为例，完整流程：

```text
# Step 1: OpenSpec explore
/opsx:explore 我的 P18 产品是 [产品描述]。
目标用户是 [用户画像]。
每次调用的硬成本约为 $0.03。
请探索定价方向，对比至少 3 种定价模型的单位经济模型。

# Step 2: Superpowers brainstorming
用 brainstorming skill 发散定价方案。
先发散（至少 5 种定价思路，包括一些看起来不合理的），
再按"用户接受度 / 成本覆盖 / 实现复杂度"收敛到 2 个推荐方案。

# Step 3: OpenSpec propose
/opsx:propose 基于 explore 和 brainstorming 的结果，
生成 pricing-proposal.md：
- 定价建议及理由
- 单位经济模型（含盈亏平衡点）
- 与竞品的价格对比
- 风险（如大用量用户吃掉毛利、定价锚点错位）

# Step 4: 人工确认
检查 AI 生成的定价建议：
- 数字是否基于你提供的成本数据？（AI 有时会编数字）
- 竞品对比是否正确？（AI 可能用了过时的价格信息）
- 盈亏平衡点的计算是否正确？（自己验算一遍）
```

**注意**：定价分析的最终决定权在人。AI 提供的是"系统性地列出所有需要考虑的因素"，不是"告诉你该定多少钱"。定价涉及你的品牌定位、用户心理、竞争策略——这些 AI 不会懂。

### 三个原则

**原则一：AI 擅长"列全"，不擅长"拍板"。** 用 AI 做决策辅助时，让它帮你列出所有需要考虑的因素、所有可能的方案、所有潜在的风险。然后你来做选择。不要问 AI "我应该选哪个"，问它"选 A 和选 B 分别会有什么后果"。

**原则二：AI 的输出必须标注"AI 生成"。** 特别是合规相关内容。你在用 AI 帮你加速，但法律责任是你自己的。隐私政策里应该标注生成日期和"本内容由 AI 辅助生成"——不是为了免责，是让你自己记住：这是草稿，不是律师意见。

**原则三：竞品信息有时效性。** AI 搜到的竞品信息可能是几个月前的。如果某个竞品的信息对你的决策有关键影响，自己去确认一下它的当前状态。产品关停、价格调整、功能更新——这些变化很快，AI 的训练数据不一定跟得上。

### 动手 5 分钟

1. 用 brainstorming skill 为你的 P18 产品做一次竞品扫描。记录至少 3 个竞品，每个竞品标注"他们做得最好的一点"和"用户最不满的一点"。
2. 用 web search 验证 AI 给出的竞品信息是否准确（至少抽查 2 个竞品的当前定价）。
3. 让 AI 为你的产品生成一份隐私政策草稿。逐条标注：模板可用 / 需修改 / 需律师审核。至少找出 3 处"需修改"的地方。

**验收标准**：竞品分析至少覆盖 3 个竞品，每个竞品有"一个优点 + 一个差评"；隐私政策草稿的三类标注清晰，且"需律师审核"的条款至少 2 处。

### 要点总结

- **OpenSpec + Superpowers 工作流同样适用于非开发任务**——竞品分析、定价建模、合规检查。这些任务你经验更少，AI 的辅助价值更大。
- **竞品扫描的核心不是"列出竞品"，是"找出所有竞品都没覆盖的空隙"并判断是机会还是坑。** AI 搜到的竞品差评和关停公告是判断的关键依据。
- **定价分析用 AI 的优势是"没有心理负担"**——AI 不会因为怕没人买而低估价格。让它列出三种方案的单位经济模型，你来做选择。
- **合规相关的 AI 产出必须三级标注**：模板可用 / 需根据实际情况修改 / 必须律师审核。AI 可以写草稿，不能替你判断合法性。
- **三个原则**：AI 擅长列全不擅长拍板、AI 产出必须标注 AI 生成、竞品信息有时效性需要自己核实。
- **最终决策权在人**。AI 帮你列出所有需要考虑的因素，但你最了解你的用户、你的定位、你的风险承受能力。AI 是参谋，不是决策者。
